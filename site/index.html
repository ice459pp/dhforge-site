Local-first · Permission-aware

讓 AI 在清楚的權限邊界內完成工作。

DSH Forge 是一套在使用者自己的電腦上運行的 AI 工作台。使用者選擇模型，透過共用的 OAuth 連線中心連接自己的第三方服務，並在每次外部寫入前確認實際目標與內容。

查看開源專案 閱讀隱私權政策

產品原則

使用者掌握帳戶、授權範圍與寫入決定

DSH Forge 不要求使用者共用第三方帳戶。每位使用者透過服務供應商的 OAuth 流程連接自己的帳戶， 依啟用的能力授予必要權限；停用服務、解除連線或在供應商帳戶中撤銷授權，均由使用者自行控制。

本機優先

連線憑證留在本機

OAuth 憑證保存在使用者的本機 DSH 憑證儲存空間，不由本專案提供共用帳戶或集中式使用者資料庫。

最小權限

供應商與能力分開啟用

每個連線供應商及其讀寫能力各自標示；新增服務不會自動沿用其他服務的權限。

逐次確認

寫入前再次核准

寄信、建立文件、寫入試算表或其他外部動作，在送往服務供應商前都需要使用者針對該次內容確認。

連線與服務

一套共用資訊頁，支援多種 OAuth 服務

DSH Forge 使用同一套產品首頁、隱私權政策與服務條款說明所有第三方連線。新增供應商時， 只需在共用服務目錄與資料用途附錄揭露實際權限，不需要為每項服務複製一套政策頁。

目前可用

Google Workspace

Gmail、Drive、Docs、Sheets、Slides、Calendar、Chat 與 People 共用一個 Google 帳戶連線，各能力仍分開授權。

共用框架

其他 OAuth 供應商

未來的 Notion、Figma 或其他服務可接入相同連線中心，但只有在實際完成並列入能力目錄後才會顯示為可用。

一致揭露

單一政策中心

帳戶資料、憑證保存、AI 處理、撤銷方式及逐次寫入核准採共同原則；供應商差異集中列於隱私權附錄。

目前的 Google Workspace 整合直接使用 Google 正式 REST API。模型只能呼叫 DSH Forge 已定義且 受限制的工具，不能提交任意網址、任意 HTTP 請求或未經同意的寫入。

Google API Limited Use 聲明 DSH Forge 對從 Google API 取得之資訊的使用與轉移，將遵守 Google API Services User Data Policy， 包括 Limited Use requirements。

資料透明度

資料只為完成使用者提出的工作而處理

連線服務內容可能顯示於 DSH 對話並依使用者選擇傳送給所設定的 AI 模型供應商，以產生要求的結果。 DSH Forge 專案不販售第三方服務資料、不用於廣告，也不以這些資料建立或訓練通用 AI 模型。 詳細保存、分享及刪除方式請參閱隱私權政策。
